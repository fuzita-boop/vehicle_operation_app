# 完全ローカルPWAへの移行手順

このアプリは、ログイン・サーバーDB・外部APIを使用せず、各端末のブラウザ内にあるIndexedDBへ運転者情報、車両情報、月次サイクル、日次記録を保存します。したがって、同じデータを複数端末で自動同期する機能はありません。

## 既存データの初回取込

既存システムの記録は、利用者ごとに分けたJSONバックアップとして提供します。対象利用者の端末で新しいPWAを初回オンライン起動した後、ホーム画面下部の「データのバックアップと復元」から「バックアップを復元」を選び、本人用のJSONファイルを選択してください。初回の取込では「復元：現在のデータを置換」を選ぶと、空の端末へ確実に移行できます。

## 日常的なバックアップ

ホーム画面の「バックアップを保存」を押すと、端末内の全データをJSONファイルとして保存できます。機種変更、ブラウザの履歴・サイトデータ削除、別端末への移行を行う前には、必ずこのバックアップを安全な場所へ保管してください。

## 復元方法の選択

「現在のデータと統合」は、既に入力済みの記録を残しながらバックアップを追加します。「現在のデータを置換」は、端末内の現在の記録を消してバックアップ内容だけにします。置換前には必ず現在の端末のバックアップを保存してください。

## オフライン利用

初回オンライン起動後は、アプリ本体の画面・JavaScript・CSS・アイコンが端末に保存されます。通信がない場所でも起動、記録の入力、月次レポートの閲覧、印刷用レイアウトの表示を行えます。バックアップファイルのダウンロードや端末の共有機能の扱いは、各ブラウザ・端末の仕様に従います。
